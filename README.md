# ShareVerse

A secure, modern, and production-ready full-stack web application that enables users to upload, organize, and securely share files and folders using unique shareable links.

## Key Features

- **Chunked Resumable Uploads**: Upload large files and folders in 2MB slices with progress metrics, ETA, and auto-resume capabilities.
- **Access Controls**: Protect download links with custom passwords, download caps, and link expiration timers.
- **In-Browser Previews**: Native support for image, video, audio, PDF, text, and CSV previews.
- **Interactive UI**: Responsive layouts, dark/light theme, and dynamic upload tracking hud.
- **Admin Dashboard**: System action logs, user role configurations, and storage utilization stats.

## Development Startup

Run the unified full-stack application on port 3001 in development mode:

```bash
npm install
npm run dev
```
